One design decision
Check evidence before writing the narrative
The first model call produces a structured ledger: source decisions, facts with exact excerpts, and conflicts. Local code checks that every excerpt occurs in its cited document.
Conflicting results
Use the primary filing; record the disagreement without guessing its cause.
Old pledge warning
Separate the historical report from the latest official position.
Hostile / wrong entity
Exclude promotional instructions and the similarly named cable-TV company.
The second call writes from that ledger. A third call checks every fact and brief point against the original sources. The brief is saved only if all checks pass. Python links directly to the source files.
documents → quoted facts → draft → model review → cited brief
Prompts are separate files. Raw responses, receipts, hashes, and failed runs are retained for inspection.


One limitation
A matching quote does not prove a correct interpretation
Schema, quote, reference, and numeric checks catch many errors. They cannot independently establish truth or prove that a cited passage supports every clause. The extra model review can also miss mistakes. Human review still matters.
The input pack is fictional. There is no live price feed, valuation model, or investment recommendation. Guidance stays conditional and dates are explicit.
What testing caught
A real run changed a fiscal year inside a quotation. The validator rejected it and kept the response. The current build allows one model correction and never replaces a quote by fuzzy matching. Earlier runs exposed speculative discrepancy explanations and a claim missing its second source.
Offline tests exercise date filtering, prompt separation, quoted evidence, numeric support, citation IDs, retry caps, credential redaction, and failure retention.
